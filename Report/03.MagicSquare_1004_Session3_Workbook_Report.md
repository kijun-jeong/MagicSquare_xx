## 2. Mom Test 결과 (고정)

### 2.1 페르소나

4×4 **부분 마방진**(빈칸 2개, 값 `1~16`, **10선** 합 34)을 과제·연습으로 손/코드로 다루는 **학습자**. 행·열은 맞추다 **대각선 확인을 늦게** 하면 숫자를 반복 바꾸며 시간을 쓰지만, 맞추면 만족하고 넘어가는 경향.

### 2.2 진짜 문제 (한 문장)

> **행·열·대각선(10선) 규칙이 동시에 걸릴 때, 확인 순서가 고정되지 않아 대각선을 늦게 보면 숫자를 반복 바꾸며 시간을 쓰고, 맞춘 뒤에는 검증 절차를 다시 쓰지 않고 넘어간다.**

### 2.3 Mom Test 증거 3줄

1. 빈칸 2개 넣고 행·열·대각선 맞췄는데 **대각선 하나 빼먹어 약 20분** 소모.
2. 20분 동안 **숫자만 바꿔 넣다** 끝에야 대각선 확인 → **합이 34가 아님**.
3. 다시 바꿔 **1분** 만에 전 축 확인·전부 맞음 → **기분 좋아 닫음** → 이후 비슷한 격자 **없음**.

## 3. 세션 3 워크북

### 3.1 주제 한 문장 (Mom Test 기반, 솔루션 최소화)

> **4×4·빈칸 2개를 채운 뒤 10선 합 34를 확인할 때, 검사 순서가 흔들려 대각선을 늦게 보면 시간이 새고, 맞춘 뒤에는 같은 검증 절차를 다시 쓰지 않는다 — 이 비용과 단절을 관찰 가능한 규칙·명령·테스트 루프로 줄인다.**

*(“앱/자동완성/Solver” 없음 — **확인 순서·검증 비용·재연습 단절**만 다룸)*

### 3.2 R-G-I-O

| | 내용 |
|:---|:---|
| **Role** | 4×4·빈칸 2·1~16·합 34를 손/코드로 다루는 **학습자**; 이번 세션에서는 **규칙·검증 절차 작성자·테스트 설계자**. |
| **Goal** | 빈칸 채운 뒤 **10선(행→열→대각) 검증 순서를 고정**하고, 불일치 시 **첫 위반 1개**만 짚을 수 있게 하며, 맞춘 뒤에도 **같은 절차를 1분 안에 재현**할 수 있게 한다. |
| **Input** | `4×4` 정수 격자; `0` = 빈칸 **정확히 2개**; 나머지 `1~16`; `0` 제외 중복 없음; *(선택)* 빈칸에 넣은 두 수. |
| **Output** | **Rule** 문장(불변식·검사 순서), **Command** 이름·전제·결과, **(Skill)** 적용 순서 메모, **Test Loop** RED 1사이클 이상. *완성 솔버·UI·전체 ECB는 이번 Output 아님.* |

### 3.3 성공 기준 3개 (Mom Test 증거와 연결)

| # | 성공 기준 | 연결 증거 |
|:---:|:---|:---|
| **SC-1** | 동일 격자에 대해 **행 → 열 → 두 대각선** 순으로 10선 합을 검사하는 절차를 **한 번에 재현**할 수 있고, 대각선이 **마지막이 아닌 고정 위치**에 포함된다. | ① 대각선 빼먹어 **20분** — 순서 고정으로 누락 방지 |
| **SC-2** | 합이 34가 **아닐 때**, **첫 번째로** 깨진 축(행/열/대각)을 **한 가지만** 보고한다. *(여러 에러 나열 금지)* | ② 숫자만 반복 교체 — **어느 축이 깨졌는지** 먼저 특정 |
| **SC-3** | SC-1·SC-2를 **Test Loop**(RED 테스트 ≥1)로 고정했고, 검사 순서·첫 위반 규칙을 바꾸면 테스트가 **의도적으로** 깨진다. | ③ **1분** 재확인 후 닫음·재연습 없음 — 절차를 **회귀 테스트로 고정**해 재사용 가능하게 |

### 3.4 표면 문제 — 이번 프로젝트에서 하지 않을 것

| 표면 문제 (하지 않음) | 이유 |
|:---|:---|

| “**대각선 자동 검사 기능**만 있으면 된다” | 기능 제안; 세션 3은 **절차·규칙·테스트**만 |
| “**TDD/ECB 전체** 한 번에 구현” | 세션 3 범위 밖; Rule·Command·Test Loop만 |
| “**모든 해** 찾기 / 탐색 최적화” | 학습자 고통(확인 순서·재검증)과 무관 |
| “합 34 **맞추는 퍼즐 풀이법** 가르치기” | Goal은 **판정·첫 위반·검증 절차 고정**, 튜토리얼 아님 |
| “에러/메시지 **대충** 비슷하면 통과” | SC-3·회귀 보호 무력화 |

### 3.5 8계층 — 이번 세션에서 만드는 것만

| 계층 | 이번 세션 산출 | Mom Test 연결 |
|:---|:---|:---|
| **Rule** | **R-01** Shape: 4×4 · **R-02** `0` 정확히 2개 · **R-03** 값 `0` 또는 `1..16`, `0` 제외 유일 · **R-04** 완성 시 10선 합 = **34** · **R-05** 검사 **순서 고정**: 행 → 열 → 대각선 · **R-06** 불일치 시 **첫 위반 1개만** 보고 | ① 대각선 누락 · ② 무작위 숫자 교체 |
| **Command** | `CHECK_ALL_LINE_SUMS(matrix)` — 10선 34 여부, **행→열→대각** 순 실행 · `REPORT_FIRST_VIOLATION(matrix)` — 첫 깨진 축·(선택) 선 인덱스 · `REVERIFY_AFTER_EDIT(matrix)` — 수정 후 **전 축 1회** 재확인 | ② 끝에야 대각선 확인 · ③ **1분** 재확인 절차 |
| **(Skill)** | 빈칸 2개 채움 → `CHECK_ALL_LINE_SUMS` → 불일치 시 `REPORT_FIRST_VIOLATION`으로 **해당 축부터** 수정 → `REVERIFY_AFTER_EDIT` → **전부 맞으면** Skill 종료(닫기 전 **1분 재현** 확인) | ② 숫자만 바꿈 → ③ 맞춘 뒤 닫음·재연습 없음 방지 |
| **Test Loop** | **RED-1**: 완성 격자에서 **한 대각선만** 틀린 경우 → 첫 위반이 **대각선** · **RED-2**: 행·열만 맞고 대각선 틀린 경우 → 검사 순서상 **대각선**이 첫 위반 · **RED-3**: 검사 순서를 바꾸면 테스트 **실패** *(회귀)* · *(GREEN/REFACTOR는 세션 4+)* | ①·③ 절차 고정·재사용 |

**이번 세션에서 만들지 않는 계층 (보류)**  
Entity 구현 전체, Boundary/UI, `solution()` 완성, 저장·로드, 스타일링 등 — 8계층 중 나머지는 다음 세션으로.
