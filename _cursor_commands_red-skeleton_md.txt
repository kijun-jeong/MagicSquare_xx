# RED Skeleton — ARRR A단계 (RED ④)

[`/red-test-plan`](red-test-plan.md) 설계표 기준 **`pytest.fail` 스켈레톤만** 작성하는 커맨드.  
`tests/`만 수정한다. `src/`는 **건드리지 않는다.**  
다음 단계: `/green-minimal` — `pytest.fail` 제거 후 최소 GREEN.

**Skill 참조:** [`.cursor/skills/magic-square-tdd/SKILL.md`](../../.cursor/skills/magic-square-tdd/SKILL.md) *(생성 예정)* — **magic-square-tdd Skill이 있으면 자동 따른다** (AAA·RED 규칙·픽스처 명명·import 경로).

## 트리거

사용자가 **`/red-skeleton`만** 입력해도 동작한다.  
추가 인자가 없으면 **직전 채팅의 `/red-test-plan` 블록 2·3**에서 자동 추출한다.

| 추출 항목 | 우선순위 |
|:---|:---|
| **Test ID** | 채팅 명시 → red-test-plan 블록 2 첫 행 |
| **파일 경로** | red-test-plan 블록 3 |
| **함수명** | red-test-plan 블록 3 |
| **Given/When/Then** | red-test-plan 블록 1·2 |
| **Layer / Track** | 채팅 → 없으면 `entity` · `Logic` |

명시적 오버라이드 예:

```
/red-skeleton
Phase: red | Layer: entity | Track: Logic
Test ID: RED-1
파일: tests/test_validate_lines.py
픽스처: tests/conftest.py (grid_g1 — 0이 2개, row-major)
```

**Track A (boundary / UI):** Layer만 `boundary`로 바꾸면 동일 규칙 재사용 *(Then은 여전히 `pytest.fail` 한 줄)*.

| 항목 | 내용 |
|:---|:---|
| **ARRR** | **A**sk — RED ④ (스켈레톤·픽스처만, assert 본문 없음) |

| **다음** | `/green-minimal` |

## AAA 절차 (주석 필수)

각 테스트 함수는 **Given → When → Then** 주석으로 구역을 나눈다.

| 구역 | 주석 | 내용 |
|:---|:---|:---|
| **Given** | `# Given: …` | 픽스처·격자·입력 *(설계표와 동일)* |
| **When** | `# When: …` | 대상 함수 1회 호출 *(호출만, 결과 검증 없음)* |
| **Then** | `# Then: …` | **기대 계약을 주석으로만** 기술 |
| **실행** | *(Assert)* | `pytest.fail("RED: {Test ID} — …")` **한 줄** |

- **Act 호출은 When에 둘 수 있음** — 단, Then에 `assert` 본문 **금지**.
- 통과하는 더미(`pass`, `assert True`, 빈 assert) **금지**.

## 상수·import 규칙

| 규칙 | 내용 |
|:---|:---|
| **매직넘버 금지** | 격자 데이터·주석 외 리터럴 `34`/`16`/`4` 직접 쓰지 않음 |
| **상수 import** | `from constants import GRID_SIZE, MAGIC_SUM, VALUE_MAX` *(분리 후 `entity.constants`)* |
| **픽스처** | conftest는 **데이터·상수만** — 도메인 판정 로직 없음 |
| **대상 함수** | `from validate_lines import validate_lines` 등 **실 import** *(Domain Mock 금지)* |

현재 저장소: `src/constants.py` · `pythonpath = ["src"]` (`pyproject.toml`).

## conftest — `tests/conftest.py`

| 픽스처 | 내용 |
|:---|:---|
| **`grid_g1`** | G1 격자 — `0` **정확히 2개**, row-major 스캔 순 `(2,2)`, `(3,3)` *(1-index 의미는 주석)* |

```python
import pytest

from constants import GRID_SIZE, MAGIC_SUM, VALUE_MAX

@pytest.fixture
def grid_g1() -> list[list[int]]:
    """G1 — 0×2, row-major 빈칸 (2,2)·(3,3) 1-index."""
    return [
        [16, 3, 2, 13],
        [5, 10, 0, 8],
        [9, 6, 0, 12],
        [4, 15, 14, 1],
    ]
```

설계표가 다른 G0~G8을 지정하면 **해당 픽스처만** 추가·사용.

## 스켈레톤 템플릿

### A — `validate_lines` · RED-1 *(세션 3 기본)*

```python
"""FR-VAL-01 / RED-1 — validate_lines 첫 대각선 위반."""
import pytest

from validate_lines import validate_lines


def test_red_1_fail_first_diagonal_violation_d1():
    # Given: 완성 격자, 행·열·D2는 MAGIC_SUM, D1만 깨짐
    grid = [
        [99, 2, 3, 13],
        [5, 11, 10, 8],
        [9, 7, 6, 12],
        [4, 14, 15, 1],
    ]

    # When: validate_lines(grid)
    result = validate_lines(grid)

    # Then: status=="fail", failed_lines==["D1"]
    pytest.fail("RED: RED-1 — assert 미구현, 의도적 실패")
```

### B — `find_blank_coords` · D-LOC-01 *(워크숍·Track B 템플릿)*

```python
"""FR-LOC-01 / D-LOC-01 — find_blank_coords row-major 1-index."""
import pytest

from loc import find_blank_coords


def test_d_loc_01_blank_coords_row_major(grid_g1):
    # Given: G1 — grid_g1 (0×2, row-major)
    grid = grid_g1

    # When: find_blank_coords(grid)
    coords = find_blank_coords(grid)

    # Then: [(2, 2), (3, 3)] — 1-index, row-major
    pytest.fail("RED: D-LOC-01 — assert 미구현, 의도적 실패")
```

- 함수명·import·Then 주석은 **red-test-plan 블록 3**과 일치.
- `pytest.fail` 메시지에 **Test ID** 포함 필수.

## 금지

| 금지 | 이유 |
|:---|:---|
| `src/` 수정 | RED ④는 tests만 |
| Then에 **assert 본문** | GREEN(`/green-minimal`) 담당 |
| `@pytest.mark.skip`, `xfail` | RED 회피 |
| `pass` · `assert True` · 통과 더미 | 약한 RED |
| Domain Mock (`unittest.mock` 등) | Logic Track — 실 import |
| 이번 묶음 **외 Test ID** 동시 해결 | 1 RED = 1 묶음 |
| GREEN / REFACTOR | Phase 혼입 |
